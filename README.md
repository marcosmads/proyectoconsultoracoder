# Proyecto Consultora RRHH

Pagina de consultora que lista los servicios brindados, una sobre el servicio de payroll, una pagina con el detalle de clientes y una exclusiva para contacto. Se incluyen imagenes de servicios y de los equipos de trabajo.

## Links:
#### Repositorio Acceso Web: [Github](https://marcosmads.github.io/proyectoconsultoracoder)

#### Producción Acceso Web: [Vercel](https://proyectoconsultoracoder-fuj2r197s-mark-6657.vercel.app)

## Contenido del Repositorio:

[_/index.html_](https://github.com/marcosmads/proyectoconsultoracoder/blob/master/index.html) Contiene la información del inicio la Página Web

[_/pages/contacto.html_](https://github.com/marcosmads/proyectoconsultoracoder/blob/master/pages/contacto.html) Sub-Página que incluye un Carousel y un Form de contacto

[_/pages/nuestro-servicio.html_](https://github.com/marcosmads/proyectoconsultoracoder/blob/master/pages/nuestro-servicio.html) Sub-Página que detalla información relacionada a los servicios de la empresa con Cards

[_/pages/nuestros-clientes.html_](https://github.com/marcosmads/proyectoconsultoracoder/blob/master/pages/nuestros-clientes.html) Sub-Página que muestra a los clientes en una grilla usando Cards


[_/pages/payroll-para-empresas.html_](https://github.com/marcosmads/proyectoconsultoracoder/blob/master/pages/payroll-para-empresas.html) Sub-Página que contiene un iframe de Vimeo

[_/scss_](https://github.com/marcosmads/proyectoconsultoracoder/tree/master/scss) Todos los Styles del Index y Sub-Páginas usando Sass
